## Installation

Run from your Cordova application directory:

```bash
cordova plugin add cordova-plugin-yandex-ads
```

Use Cordova CLI 13+ and Cordova Android 15+ with the standard platform toolchain. Kotlin and the iOS deployment target are configured by the plugin; a new application needs no custom build preferences or helper scripts.

See the [English documentation](docs/en/README.md) for platform requirements and usage, or the [migration guide](docs/en/MIGRATION.md) when upgrading from SDK 7.
